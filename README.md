## 고치고 싶을 때

- 글: `index.html`에서 해당 `<section class="slide">` 안의 텍스트를 바로 고칩니다.
- 사진: `assets/img/`에 넣고 `<img src>`를 바꿉니다. 사진 크기는 `<figure>`의 `style`에 적힌 `width`와 `height`가 정하고, 사진은 그 틀에 맞춰 잘립니다. 잘리는 위치는 `<img>`의 `object-position`으로 조정합니다 (8번 슬라이드 참고).
- 단계 등장: 문단에 `class="fragment"`를 붙이면 다음 키를 눌러야 나타납니다. 여러 요소를 한 번에 나오게 하려면 같은 `data-frag="이름"`을 붙입니다 (11번 슬라이드 참고).
- 강조 단어: `<b class="hl">단어</b>` (19번 슬라이드 참고).
- 색: `assets/css/deck.css` 맨 위 `:root`의 `--bg`(배경), `--text`(글), `--accent`(강조색).
- 타임라인 구간: `assets/js/deck.js`의 `chapters` 배열. `start`는 0부터 세는 슬라이드 번호입니다.
- 브라우저 탭 제목: `index.html`의 `<title>`.

고친 뒤 `main`에 push하면 GitHub Pages가 1~2분 안에 다시 배포합니다. 배포 상태는 저장소의 Actions 탭에서 "pages build and deployment"로 확인할 수 있습니다.
